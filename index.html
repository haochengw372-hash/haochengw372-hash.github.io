Clip AI Card

Personal Agent 软硬件

官网与概念演示已上线 · 硬件在研
问题

想法和材料出现在日常里，但交给 Agent 前，要先打开电脑、整理上下文、反复授权。

方案

一张可折叠的卡片，连接眼前的材料与已授权的 Agent：语音 / 视觉采集 → 上下文预览与授权 → Agent 执行 → 状态回执。

  • 卡片 · iPhone · Mac 三端协同
  • 先预览、再发送：采集与发送分别授权
  • Mac 直连方案支持原始材料留在本地

02

MeetFlow

Personal AI Company · 数字员工

研发及内部测试中 · 京彩 OPC 二等奖
问题

AI 能力不等于 AI 劳动力：工具没有岗位、没有项目上下文、没有组织协作，管理工作仍然压在人身上。

方案

面向个人与 1–20 人小团队的 AI 公司：用户只提出 Goal，MeetFlow 生成 Mission，分派给有长期记忆的数字员工，再调度 Codex / Claude 等 Worker 执行。Founder 只处理 Decision 和 Acceptance。

  • Goal → Mission → 岗位 → 员工 → Worker 执行体系
  • 区分长期记忆「员工」与一次性任务「Worker」
  • 任务路由、跨 Mission 记忆、进度看板、人工验收
  • 定价：1,499 / 4,999 元每月，按员工与团队收费

03

SparkFlow

AI 专业文档共创平台

挑战杯首都创业计划竞赛三等奖 · 京彩三等奖
问题

高校科研、产品经理、文创策划等高压交付人群，需要的不是「代写」，而是能把专业判断变成高质量文档的搭档。

方案

「不替代思考，只放大专业表达」：通过结构化追问澄清需求，调用 Expert Skills 与 Agentic RAG 生成初稿，再进入人工审校与后续行动。

  • 结构化追问 → 初稿 → 审校 → 任务列表的完整链路
  • 首批 Skills：「艺术家访谈」「音乐会策划」
  • 把专家判断、追问节点、输出模板沉淀为可复用资产
